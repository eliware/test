# Support

For questions or failures, use the
[Eliware Discord community](https://discord.gg/M6aTR9eTwN),
[GitHub issues](https://github.com/eliware/test/issues), or email
eliware@eliware.org.

Include the command, Node.js version, and redacted diagnostics.
Do not share secrets, credentials, private runtime data, or unreviewed output.
