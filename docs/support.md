# Support

Ask a question in the [Eliware Discord community](https://discord.gg/M6aTR9eTwN).
Report a defect in [GitHub issues](https://github.com/eliware/test/issues).
Email `eliware@eliware.org` for direct support.

Include the command, Node.js version, and full diagnostic.
Remove credentials, tokens, private environment values, and other private data first.
Do not share coverage files or generated output.
