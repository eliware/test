# Eliware Test documentation

Use these guides to set up Eliware Test and validate a repository.

## Start here

- [Usage](usage.md): install the package, set profiles, and run commands.
- [Profiles](profiles.md): choose the profiles for a repository.
- [Validation](validation.md): learn what aggregate and focused runs check.
- [Smoke test](smoke.md): test a packed package in a prepared consumer.
- [Troubleshooting](troubleshooting.md): diagnose failures and read exit codes.
- [Support](support.md): ask for help or report a problem.

## Requirements

Use Node.js 26 or later and npm 12 or later.
Read each profile's convention files for its exact requirements.
