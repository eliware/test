# Minimal consumer example

This runnable example demonstrates the primary `@eliware/test` workflow with a
mirrored `src/` and `tests/` tree.

## Prerequisites

- Node.js 26 or newer
- npm

## Usage

Run `npm install`, then `npm test` and `npm run lint` from this directory.

Expected results are a passing Jest run with 100×4 coverage and zero lint
warnings. This example uses placeholders only; never add real secrets or
private endpoints. Return to the [examples index](../README.md).
