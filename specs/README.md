# Test specifications

This directory contains the normative specification index for the Eliware
validation harness.

## Files

- [directives.json](directives.json) — harness directives.
- [authority.json](authority.json) — Test-local authority distribution.
- [convention-remediation.json](convention-remediation.json) — Generated v8 remediation guidance snapshot for bundled checks. Regenerate it from the adjacent `eliware/conventions/specs` directory with `node scripts/sync-convention-remediation.mjs` when directive guidance changes.
